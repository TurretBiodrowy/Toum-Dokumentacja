# Viper

### *Rozpuść ciała!*

**Przynależność: Imp Killing (Zabijający)**

**Viper** zamiast zwykłego przycisku **Kill**, posiada przycisk **Acid**.\
Używając tego przycisku na ofierze, zabije go, a ciało zostanie pokryte kwasem. Ciało pokryte kwasem zniknie po ustawionym czasie.
