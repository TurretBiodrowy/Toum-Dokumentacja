# Host-Specific Options

| Ustawienie                          |                                                 Opis                                                 |     Typ     | Domyślnie |  Wartość  |
|-------------------------------------|:----------------------------------------------------------------------------------------------------:|:-----------:|:---------:|:---------:|
| Enable Anti Cheat Warnings          |       Ustawia czy Host dostaje powiadomienia gdy ktoś wchodzi do lobby z innym zestawem modów        | Przełącznik |    Tak    | Tak / Nie |
| Kick Players Using Cheat Mods       |                    Automatycznie wyrzuca graczy korzystających ze znanych cheatów                    | Przełącznik |    Tak    | Tak / Nie |
| Freeplay Mode                       | Decyduje czy gra będzie w trybie Freeplay (Gra się nie skończy, i będzie dostęp do opcji debugowych) | Przełącznik |    Nie    | Tak / Nie |
| Allow Lobby-Only No-Clip            |                      Ustawia czy gracze mogą chodzić przez ściany tylko w Lobby                      | Przełącznik |    Tak    | Tak / Nie |
| Show Rules to Players on Lobby Join |             Decyduje czy ustawione zasady będą automatycznie pokazane dla każdego gracza             | Przełącznik |    Tak    | Tak / Nie |
| Allow Spectators                    |                          Decyduje czy gracze mogą korzystać z komendy /spec                          | Przełącznik |    Nie    | Tak / Nie |
