# Investigator

### *Widzisz ślady innych graczy!*

**Typ: Utility (Użytkowy)**

Gracz z modyfikatorem **Investigator** będzie widział ślady innych graczy, które zanikają po czasie.

### Opcje
#### Opcje tego modyfikatora ustawia się w kategorii roli Investigator

| Ustawienie             |                            Opis                            |     Typ     | Domyślnie |  Wartość  |
|------------------------|:----------------------------------------------------------:|:-----------:|:---------:|:---------:|
| Footprint Size         |                  Ustawia rozmiar śladów.                   |   Mnożnik   |    4x     |  1x-10x   |
| Footprint Interval     |           Co jaki czas nowy ślad jest tworzony.            |    Czas     |   1.0s    |  0.5s-6s  |
| Footprint Duration     |           Jak długo ślady są widoczne na ziemi.            |    Czas     |    10s    |  1s-15s   |
| Anonymous Footprints   |   Ustawia czy ślady mają kolor gracza który je zostawił.   | Przełącznik |    Nie    | Tak / Nie |
| Footprint Vent Visible | Ustawia czy ślady gracza który jest w ventcie są widoczne. | Przełącznik |    Nie    | Tak / Nie |
