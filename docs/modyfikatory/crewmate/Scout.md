# Scout

### *Widzisz więcej w świetle, ale mniej w ciemnościach!*

**Typ: Visibility (Widoczność)**

Gracz z modyfikatorem **Scout** będzie miał nielimitowaną wizję gdy będą włączone światła ale, gdy zostanie uruchomiony sabotaż świateł nie będzie mógł nic widzieć.
