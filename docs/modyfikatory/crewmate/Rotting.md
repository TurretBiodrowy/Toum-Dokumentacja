# Rotting

### *Twoje ciało gnije gdy umrzesz!*

**Typ: Postmortem (Pośmiertny)**

Zabicie gracza z modyfikatorem **Rotting** spowoduje, że jego ciało po paru sekundach zniknie.\
Ciało gracza **Rotting** będzie pokryte kwasem.

### Opcje
