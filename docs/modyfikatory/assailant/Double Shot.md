# Double Shot

### *Masz drugą szansę gdy źle zgadniesz!*

**Typ: Utility (Użytkowy)**

**Double Shot** może zostać przyznany tylko **Impostorowi** bądź **Neutralnemu Zabójcy** z umiejętnością **Assassin**.\
Gdy gracz z tym modyfikatorem pierwszy raz w grze źle strzeli rolę, nie umrze.
